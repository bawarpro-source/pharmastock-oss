# Roadmap

## Available in v0.1.0
- Deterministic CSV reconciliation by branch, SKU and batch
- Data validation and basic tests
- CSV report generation

## Proposed (not implemented)
- Count session timestamps and accountable operators
- Stock movement adjustment between export and count
- Optional barcode scanning interface
- Expiry date validation and alerts
- Web UI, authentication, roles and audit trails
- Excel import and export
- Configurable units (packets/sheets) with explicit conversions
- Accessibility, localisation, and more edge-case tests

Please open an issue to discuss priorities before starting substantial features.
