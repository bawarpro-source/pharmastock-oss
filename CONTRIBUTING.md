# Contributing

Thank you for contributing to PharmaStock OSS!

1. Check existing issues or open a proposal before large changes.
2. Fork the repository and create a focused feature branch.
3. Install with `python -m pip install -e '.[dev]'`.
4. Add tests for new behaviour and run `python -m pytest -q` and `ruff check .`.
5. Open a pull request describing the change, tests and any CSV compatibility implications.

Please use synthetic examples only. Do not commit private stock, supplier, employee, or patient information. Be respectful and constructive; see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
